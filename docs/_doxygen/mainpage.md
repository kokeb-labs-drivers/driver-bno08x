# BNO08X Driver API reference {#mainpage}

The classes, types and registers of the BNO08X driver, generated from the headers in `inc/`.

Start with bno08x::BNO08X, the driver, and bno08x::I2cInterface, the base of the port you write. Errors are
bno08x::Error inside bno08x::Result; the configuration is bno08x::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">BNO08X Driver
documentation</a>.
