Detailed Description

One thing the driver reports, taken with Bno08x::PopEvent().

For a sensor sample v holds the report's fields in the order of the reference manual's table, as signed 32-bit integers in the report's own units (its Q point is QPoint()): for example v[0..2] = x, y, z of an accelerometer, v[0..3] = i, j, k, real and v[4] = accuracy of a rotation vector. docs/sensors.md lists every layout.
