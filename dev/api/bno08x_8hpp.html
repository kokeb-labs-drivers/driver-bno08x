Detailed Description

BNO08x driver: the one header to include.

Copyright
Copyright (c) 2026 The driver-bno08x authors. SPDX-License-Identifier: MIT

bno08x::Bno08x<Port> drives one CEVA BNO080, BNO085 or BNO086 smart sensor hub through a platform port you write (see bno08x_interface.hpp): SHTP framing and the SH-2 protocol over I2C, SPI or UART, or the stand-alone UART-RVC frames. The driver has no platform code, allocates nothing, throws nothing, takes no lock and is not thread-safe: give each object one owner, or guard it with one mutex. No call waits on the hub: Begin() starts a session, Poll() advances it, and every exchange with the hub is an operation that finishes later with an OpDone event.
