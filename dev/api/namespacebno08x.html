◆ CalStep

enum class bno08x::CalStep : uint8_t
strong

Steps of the calibration procedure (CAL 1000-4044, DS S3.1).

Enumerator
EnableSensors 

Enable accelerometer and magnetometer calibration; Game Rotation Vector and Magnetic Field at 50 Hz or faster.

MovePoses 

Move the device through 4 to 6 orientations, about 1 s each.

SetDown 

Set the device down for 2 to 3 s so the gyroscope calibrates.

RotateAxes 

Rotate about 180 degrees around each axis, about 2 s each.

WaitAccuracy 

Wait until the magnetometer accuracy reads medium or high.

Save 

Save the DCD.

Done 

The calibration is stored.
