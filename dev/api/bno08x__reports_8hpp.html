Each sensor report (RM S6.5, Figures 82 to 122) is a list of fields at fixed offsets. The table below lists them in the order of the reference manual; DecodeSensor() turns a report into an Event. Names, Q points and the metadata record of every sensor are tables too, so no function here branches per sensor.
