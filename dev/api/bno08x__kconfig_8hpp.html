Detailed Description

Optional ESP-IDF layer: a Config and the buffer Limits built from CONFIG_BNO08X_* options.

Copyright
Copyright (c) 2026 The driver-bno08x authors. SPDX-License-Identifier: MIT

Include this header only where you want menuconfig to choose the defaults; the driver never includes it and no driver signature depends on it. Under ESP-IDF the values come from sdkconfig.h. Without Kconfig every option falls back to the driver's default, so KconfigDefaults() equals Config{} and KconfigLimits equals DefaultLimits.

Kconfig writes a bool option set to "n" as an absent macro, so an absent option means off.

One configuration per program: the inline functions below depend on the CONFIG_ macros, so every translation unit of one program must see the same values (ESP-IDF has one sdkconfig.h per build; each host test is its own program). No driver or library header includes this one.
