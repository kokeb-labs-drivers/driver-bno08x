Detailed Description

Public types of the BNO08x driver: errors, Result<T>, configuration, events and the integer unit helpers.

Everything here is plain data with no platform dependency. The driver is integer-only: sensor values keep the Q point the SH-2 reference manual gives them (RM S6.5), and the helpers at the end of this file convert them to whole units (millimetres per second squared, milliradians per second, nanotesla, microradians, centidegrees).
