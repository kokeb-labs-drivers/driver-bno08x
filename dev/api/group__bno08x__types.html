◆ Error

enum class bno08x::Error : uint8_t
strong

Why a call failed. Every call of the driver returns one of these in its Result.

Values 0 to 9 are the shared base set; chip-specific values start at 16. DeviceIdMismatch and Crc exist for the shared base set only: this chip has no ID register to check and its links carry no CRC, so the driver never returns them.

Enumerator
Ok 

The call succeeded.

NotInitialized 

Begin() has not been called, or the session faulted.

InvalidArgument 

An argument or a Config field is out of range; nothing was sent.

Bus 

A port hook returned false.

Timeout 

The hub did not answer in the allowed time.

DeviceIdMismatch 

Base value; never returned (the BNO08x has no ID register).

Crc 

Base value; never returned (no link of this chip carries a CRC).

Busy 

The operation queue is full, or a transmit is still pending.

DeviceFault 

The hub reported a failure inside a response (a status or error code).

Unsupported 

The hook or silicon feature this call needs is absent.

Framing 

A frame rule was broken and the engine resynchronised.

HubReset 

The hub restarted; the operation was abandoned.

Overflow 

The event queue or a cargo buffer was full.

Refused 

The hub answered with a failure status (for example an FRS status).

Oversize 

A request does not fit one write transfer; nothing was sent.

NotAdvertised 

The channel or report was never advertised by the hub.

Variant 

The feature is not available on the configured chip.
