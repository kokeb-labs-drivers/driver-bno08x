Detailed Description

template<typename Derived>
class bno08x::HubInterface< Derived >

CRTP base of the platform port.

Derive class MyPort : public bno08x::HubInterface<MyPort>, add static constexpr Transport kTransport and implement the hooks of your transport. The base declares no hook itself (a forwarding hook would turn a missing override into infinite recursion).
