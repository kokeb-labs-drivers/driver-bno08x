Every figure on this site is drawn by a Python module from facts extracted from the code, so it is rebuilt, not redrawn, when the code changes. CI runs kokeb-docs figures --check and fails when a committed figure no longer matches the code. Each figure below lists the files it is drawn from.

The layers, one of them yours¶

Figure description and sources

Top to bottom, each arrow is a call. Your application calls one object, whose public calls are listed from the umbrella header in inc/. The core turns each call into register reads and writes and hands them to the port contract (the CRTP base in inc/*_interface.hpp), which forwards them, at compile time, to the hooks of the port class you write; your port moves the bytes on the bus. The notes on the right say which layers stay the same on every MCU and which one you write. A library without a port contract has only the first two layers.

I2C timing of a read¶

Figure description and sources

The three lanes are H_INTN, SCL and SDA, left to right in time. The hub holds H_INTN low until it has seen its address; the host then clocks the address bits A6 to A0 (A4 to A2 left out) and R on SDA, each stable while SCL is high, and the hub pulls SDA low for the acknowledge. After the second gap, which leaves out the data bytes, the host's NAK and the stop condition close the read; the table gives each interval with its datasheet value.

One sample through the layers¶

Figure description and sources

Participants, left to right: Your code, Bno08x, Your port and BNO08x. The steps run from top to bottom. Your code sends SetFeature(RotationVector, 10 ms) to Bno08x. Bno08x returns OpId to Your code. Bno08x sends I2cWrite(set feature cargo) to Your port. BNO08x returns H_INTN low to Your port. Your code sends Poll(now) to Bno08x. Bno08x sends IntAsserted(), I2cRead(header, rest) to Your port. A note over Bno08x says: reassemble, timestamp, decode. Bno08x returns Event Sensor on PopEvent() to Your code.

Session states of the driver¶

Figure description and sources

Six states. The session starts in Idle. Begin() leaves Idle for Resetting when NRST is wired, for WaitAdvert when it is not, and for Ready on UART-RVC. Resetting goes to WaitAdvert when the reset wait is over. WaitAdvert goes to WaitReady once the advertisement is parsed, and WaitReady goes to Ready when the reset is complete. Ready goes back to WaitReady when the hub restarts. Resetting is also entered by HardReset() and by framing faults. Faulted is reached from Resetting when NRST cannot be released and from WaitAdvert or WaitReady on a start-up timeout, and Begin() or HardReset() lead from Faulted back to Resetting.

SPI timing with the wake handshake¶

Figure description and sources

The six lanes are WAKE, H_INTN, H_CSN, CLK, MOSI and MISO, left to right in time. WAKE (the PS0 pin after reset) falls, the hub asserts H_INTN, the host pulls H_CSN low and H_INTN is released; CLK idles high, the hub reads MOSI on each rising edge and MISO carries its bits D7 to D0. The table gives each interval with its datasheet value.

UART-SHTP character¶

Figure description and sources

The two lanes are H_INTN and TX, left to right in time. The hub pulls H_INTN low, then TX sends the start bit, the data bits D0 to D7 and the stop bit; H_INTN is released before the end and asserted again for the next message. The table gives the bit rate, the byte gap the host must keep and the interrupt times.
